# Lessons Learned

## Key Takeaways

- Parent Process analysis is essential during investigations.
- CommandLine provides valuable evidence.
- Hidden PowerShell is not always malicious but requires validation.
- Encoded commands are commonly used by attackers.
- Invoke-WebRequest is frequently abused to download malware.
- Sysmon significantly improves Windows visibility.
- Splunk SPL enables efficient threat hunting.
